## 1. 页面清单

| 页面 | 路径/标识 | 说明 |
|------|----------|------|
| 主页 | `home` | 打开图片入口（空状态） |
| 编辑器 | `editor` | 单窗口编辑器：画布 + 检查器 + 工具栏 |

## 2. 主页状态

| 状态 | 触发 | UI 表现 | 可交互元素 |
|------|------|---------|-----------|
| `home_empty` | 启动未打开文件 | 大拖拽区 + "打开"按钮 + 格式说明 | 拖拽、打开按钮 |
| `home_loading` | 正在打开/解码 | 局部加载指示 | 可取消 |

## 3. 编辑器状态（核心）

| 状态 | 触发 | UI 表现 | 可交互元素 | 出口 |
|------|------|---------|-----------|------|
| `editor_loading` | 图片解码完成，OCR 执行中 | 画布显示图片 + OCR 进度指示 | 缩放/平移 | OCR 完成 → `editor_idle` |
| `editor_idle` | OCR 完成，无选中块 | 画布：图片 + 所有文字块虚线框；低置信度块弱化 | 点击块、拖动块、缩放块、添加块、删除块、合并块 | 点击块 → `editor_selected` |
| `editor_selected` | 点击某文字块 | 选中块高亮 + 检查器面板显示（文字内容/字体识别结果/字号/颜色/间距） | 编辑内容、改字体、调字号/颜色、撤销/重做、导出 | 改内容 → `editor_preview`；改动样式 → 实时生效 |
| `editor_preview` | 修改内容即时预览 | 抹除+重绘实时渲染到画布；若近似匹配显示黄色提示条 | 确认、继续调整、撤销 | 确认 → `editor_idle` |
| `editor_notext` | OCR 未检出任何文字 | 提示"未检测到文字" + 引导手动框选 | 添加文字块 | 手动框选成功 → `editor_selected` |

## 4. 全局叠加状态（可叠加于上表）

| 状态 | 触发 | UI 表现 | 交互 |
|------|------|---------|------|
| `overlay_processing` | 抹除/重绘执行中 | 选中块局部微进度 | 其他操作不阻塞 |
| `overlay_font_mismatch` | 字体比对全部低于阈值 | 黄色提示条"近似匹配：XX 字体" | 可手动换字体 |
| `overlay_export_success` | 导出成功 | 成功提示 + 文件路径 | 关闭提示 |
| `overlay_export_error` | 导出失败 | 错误提示 + 重试 | 重试/放弃 |

## 5. 状态转移约束（QA 必测）

1. `editor_loading` 期间禁止选中操作
2. `editor_idle` → `editor_selected` 只能经由点击有效文字块
3. `editor_selected` → `editor_preview` 仅在内容变更时进入，样式调整不触发内容重绘（避免抖动）
4. `editor_notext` 下"添加文字块"成功必须直接进入 `editor_selected`（闭环，不留悬空态）
5. 所有 `overlay_*` 状态不得阻断编辑主链路

## 6. 各状态验收要点

- `editor_idle`：所有文字块可点选、低置信度块可见弱化标记
- `editor_selected`：检查器数据与块绑定正确；改字体下拉含全部系统字体
- `editor_preview`：重绘与原块宽度一致（不破排版）
- `editor_notext`：引导文案清晰，手动框选可闭环
