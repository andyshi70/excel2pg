## 1. 主流程（自动识别 → 改字 → 导出）

```
┌──────────────┐
│  打开图片      │  拖拽 or 文件对话框（PNG/JPEG/HEIC）
└──────┬───────┘
       ▼
┌──────────────┐
│ 自动 OCR 检测  │  输出文字块列表（内容/边框/置信度）
│ 框选所有文字块 │
└──────┬───────┘
       ▼
┌──────────────────────────────┐
│ 低置信度块弱化标记？              │
│ └─ 是 → 用户人工确认/修正         │
│ └─ 否 → 直接进入下一步            │
└──────┬───────────────────────┘
       ▼
┌──────────────────────┐
│ 点击文字块 → 编辑态     │  ← 用户操作点
│ · 检查器显示识别结果     │
│ · 样式分析已自动完成：    │
│   字体（渲染比对/近似）   │
│   字号/颜色/字间距       │
└──────┬───────────────┘
       ▼
┌──────────────────────┐
│ 修改文字内容            │
│ · 实时预览重绘效果       │
│ · 不满意？              │
│   └ 手动改字体/字号/颜色 │
│   └ 撤销/重做           │
└──────┬───────────────┘
       ▼
┌──────────────────────┐
│ 确认修改（抹除+重绘已执行）  │
└──────┬───────────────┘
       ▼
┌──────────────────────┐
│ 导出 PNG/JPEG           │  原分辨率无损
└──────────────────────┘
```

## 2. 兜底线（OCR 不完美 / 识别不准时的后手）

```
自动框选不满意？
├─ 文字块位置/大小不准 → 拖动块 / 拖拽缩放手动修正
├─ 漏检的文字 → 工具栏"添加文字块"手动框选 → 框内重新 OCR / 直接编辑
├─ 误检（把图案当文字）→ 删除文字块
├─ 一句话拆成多块 → 手动合并相邻块
└─ 字体识别不准 → 检查器手动改字体（下拉选择系统字体）
```

## 3. 异常分支

| 触发 | 行为 |
|------|------|
| OCR 未检出任何文字 | 进入"无文字状态"：提示 + 引导手动框选 |
| 字体比对全部低于阈值 | 近似匹配 + 黄色提示条 + 手动换字体入口 |
| 新文字过长，缩到最小字号仍超界 | 提示"扩大文字块或缩短文字" |
| 重绘与相邻文字块碰撞 | 碰撞检查提示，用户调整后再确认 |
| 抹除/重绘执行中 | 局部进度指示，不阻塞其他操作 |
| 导出失败（权限/磁盘） | 明确错误提示 + 重试 |

## 4. 关键操作点汇总（QA 验收时逐条覆盖）

1. 打开图片（拖拽 + 对话框两入口）
2. 自动框选完成（低置信度标记可见）
3. 点击文字块进入编辑
4. 修改内容实时预览
5. 手动修正文字块（拖动/缩放/删除/合并）
6. 手动添加文字块
7. 字体手动替换
8. 撤销/重做
9. 导出成功 + 路径提示
